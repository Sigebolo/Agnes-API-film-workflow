# Agnes 2.5 Upgrade Design — Default 2K + Thinking + Multi-Image

Date: 2026-09-09 | Status: approved | Scope: agnes-image-2.5-flash + agnes-2.5-flash (chat)

## 1. Goal

Leverage free tier to maximize quality: unify to `agnes-image-2.5-flash`/`agnes-2.5-flash`, default `2K + ratio + composition preserve + high-density`, enable `Thinking (budget 4096)` + vision `image_url` for prompt generation, and add multi-image synthesis + high-density poster mode.

Non-goals: switching to `/v1/responses` or `/v1/messages` (Anthropic compat), streaming (deferred).

## 2. Architecture Overview

- **Model unification**: remove `2.1 vs 2.0` branch. All image calls use `agnes-image-2.5-flash` (`src/utils/api.ts:90,169`, `LogoGenerateStep:116`, `ProductImageStep:119`, `mfilm.py:556`). Text calls already on `agnes-2.5-flash` (`api.ts:22`, `server.ts:272,1555,1662,1833`).
- **Image payload**: `{model, prompt, size:"2K", ratio, extra_body:{image:string[], response_format:"url"}}`. Top-level `image/strength/tags/response_format` removed. `return_base64` (t2i) vs `extra_body.response_format:"b64_json"` (i2i) per spec.
- **Chat payload**: add `chat_template_kwargs:{enable_thinking:true, budget_tokens:4096}` (ad-video 6144), `max_tokens:4096`, dual usage-field parsing, `image_url` content blocks when reference image exists.
- **Proxy**: `server.ts:/api/proxy/images` transparent; add `url || b64_json` parsing and `size/ratio` whitelist (fallback map for legacy `1024x768`).

## 3. Image Pipeline

- **Size/ratio mapping** (per spec table):
  - Logo: `1:1 → 2048x2048 (2K)` locked
  - Product: `1:1 default` + selector `3:4/4:3/16:9/9:16/2:3/3:2/21:9`; `2K default`, `1K/4K` optional
  - Video cover/first-frame: `16:9 → 2624x1472 (2K)`, cropped downstream to 1920x1080
  - Legacy `1024x768` → `1K/4:3` normalized
- **Multi-image**: `extra_body.image: [logoUrl, productUrl]` (≤4, first 3 free, currently all free). Requires public URL via `POST /api/upload-image` (compress 1024, 0.85) already in `ProductImageStep:94`.
- **High-density**: poster/complex scenes inject `high information density, intricate details` prefix, auto-switch `2K/3K`.

## 4. Chat Pipeline (Prompt Generation)

- **Endpoints**: `/api/logo/generate`, `/api/product-image/generate`, `/api/ad-video/generate-prompt`, `/api/analyze-character` + `src/utils/api.ts:optimizePromptApi`.
- **Thinking**: always on, free. If `finish_reason===length` retry with `max_tokens 6500`. Parse both `prompt_tokens/completion_tokens` and `input_tokens/output_tokens`.
- **Vision**: when `imageUrl`/`sourceImage` is http URL, send `messages:[{role:"user", content:[{type:"text", text: product+adCopy}, {type:"image_url", image_url:{url}}]}]`. Base64/data URI first uploaded then sent as URL. No change to fallback (`fallbackPrompts`) — chat failure never blocks image gen.
- **Defer**: `stream:true` and tool calling not added now.

## 5. Frontend UX

- **Selectors** (memory via `localStorage`): `Quality: 1K | 2K★ | 4K` + `Ratio` row on `LogoGenerateStep`, `ProductImageStep`, `AdVideoStep`. Logo locks 1:1.
- **Multi-ref**: `ProductImageStep` → `+ Add logo/multi-image` (up to 4 thumbnails, reorder). `LogoGenerateStep` → optional drop of product photo as style ref.
- **Poster toggle**: `High-density details` switch in `ProductImageStep`.
- **Errors**: distinguish `public URL unreachable` / `timeout 180→300s` / `b64_json` handling.

## 6. CLI & Docs

- **mfilm.py**: `cmd_logo/cmd_image` switch to `2.5` + `size/ratio/--refs`, support `extra_body.image[]`, increase timeout to 300s.
- **Docs**: update `2026-06-26-workflow-optimization-capability.md:31-34`, `2026-06-27-storyboard-design.md:71`, `AD_PRODUCT_PLAN.md:107-109` to `2.5 + size/ratio + extra_body`.
- **Testing**: unit for `server.ts` url/b64 parsing, contract test `size/ratio/extra_body`; manual `curl 2K/16:9 single` + `2K/1:1 multi (logo+product)`; `npx tsc --noEmit` + `vitest` gate.

## 7. Rollout Order

1) Backend unify + Thinking + image_url (1d)
2) Frontend selectors/multi/poster (1d)
3) CLI + E2E + docs (0.5d)

Free tier: default `2K` everywhere; no cost branching.

## 8. Risks

- Public URL required for `extra_body.image` — handle upload fallback to text-only.
- Larger `2K/4K` → higher latency; keep gap 2s sequential gen (existing logic).
